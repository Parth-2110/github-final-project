# GitHub Final Project

This project contains a simple interest calculator that calculates the interest earned on a principal amount over a specified period.

## Description

The Simple Interest Calculator uses the following formula:

**Simple Interest = (Principal × Rate × Time) / 100**

Where:
- **Principal:** The initial amount of money.
- **Rate:** The annual interest rate in percentage.
- **Time:** The time period in years.

## Input

The calculator accepts three inputs:
- Principal amount
- Annual interest rate
- Time period in years

## Output

The calculator displays the simple interest calculated using the formula.

## Usage

Run the `simple-interest.sh` script in a Bash-compatible terminal and enter the requested values.

## Example

For a principal of 1000, an annual interest rate of 5%, and a period of 2 years:

Simple Interest = (1000 × 5 × 2) / 100 = 100
